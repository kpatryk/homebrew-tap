# Kpatryk Tap

## How do I install these formulae?

`brew install kpatryk/tap/<formula>`

Or `brew tap kpatryk/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kpatryk/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
